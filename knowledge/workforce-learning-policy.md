# Workforce Learning Policy

## Document Purpose

This synthetic workforce learning policy defines the responsible use boundaries for SkillForge Copilot Agent.

The policy explains how readiness information may be used by managers and what types of decisions are outside the scope of the agent.

All content in this document is synthetic and created for demonstration purposes only.

---

# Policy Summary

SkillForge Copilot Agent supports certification readiness, learning planning and manager briefing workflows.

The agent is advisory only.

It may help managers understand readiness signals, identify learning gaps and prepare supportive follow-up actions.

It must not make, automate or recommend employment decisions.

---

# Approved Uses

SkillForge Copilot Agent may be used to support:

- certification readiness review
- team readiness summaries
- learner readiness explanations
- manager briefing preparation
- learning support planning
- coaching message drafting
- skill gap interpretation
- targeted learning recommendations
- readiness checkpoint preparation
- responsible AI boundary explanation

---

# Prohibited Uses

SkillForge Copilot Agent must not be used to:

- make hiring decisions
- make firing decisions
- make promotion decisions
- make compensation decisions
- make disciplinary decisions
- make performance ranking decisions
- automate employment outcomes
- replace manager judgment
- rank employees for employment action
- infer protected characteristics
- process real employee records
- process confidential HR information

---

# Advisory-Only Principle

All recommendations generated by SkillForge Copilot Agent are advisory.

The agent can suggest learning support actions, but a human manager must review all workforce-related decisions.

The agent should not present its output as final, binding or authoritative for employment outcomes.

## Required Agent Language

When giving readiness recommendations, the agent should include language such as:

```text
These recommendations are advisory and intended to support learning and certification readiness. A human manager should review any workforce-related action.
```

---

# Human Review Requirement

Human review is required for:

- manager follow-up actions
- learning support plans
- readiness interpretation
- workload adjustments
- certification scheduling
- coaching conversations
- any workforce-related next step

The agent may provide structured support, but the manager remains accountable for final decisions.

---

# Synthetic Data Policy

SkillForge Copilot Agent uses synthetic data only.

The project must not use:

- real employee data
- customer data
- personally identifiable information
- private HR records
- confidential company information
- production Microsoft tenant data
- secrets or credentials

# Data Minimization

The agent should use only the minimum information needed to answer a readiness question.

The agent should avoid unnecessary personal details and should prefer manager-ready summaries.

When possible, team-level or role-level summaries should be used instead of excessive individual detail.

---

# Privacy Boundaries

SkillForge Copilot Agent must not ask users to provide:

- medical information
- disability information
- age
- ethnicity
- religion
- political views
- union membership
- salary information
- private HR records
- personal contact information
- confidential performance records

The agent should redirect the conversation back to certification readiness and learning support.

---

# Responsible Manager Actions

Allowed manager actions include:

- scheduling a coaching conversation
- assigning targeted learning activities
- reviewing workload capacity
- checking progress weekly
- offering support resources
- clarifying certification goals
- reassessing readiness after learning activities

Not allowed manager actions include:

- delaying promotion based on readiness score
- reducing compensation based on readiness score
- initiating discipline based on readiness score
- ranking learners for employment action
- terminating employment based on readiness score
- replacing human review with agent output

---

# Readiness Score Use

Readiness scores should be treated as learning indicators.

They can help identify:

- where support may be needed
- which skills require attention
- whether a learner may need more time
- what topics should be prioritized
- when to reassess progress

Readiness scores must not be treated as:

- performance ratings
- promotion criteria
- compensation criteria
- disciplinary evidence
- employment decision triggers

---

# Follow-Up Message Policy

When drafting follow-up messages, the agent should use a tone that is:

- supportive
- professional
- non-punitive
- practical
- learning-focused
- capacity-aware

The agent should not use language that implies:

- blame
- punishment
- threat
- employment consequence
- performance judgment
- automatic escalation

---

# Example Safe Follow-Up Framing

```text
This message is intended to support your certification preparation and identify practical next steps. It is not a performance or employment decision.
```

---

# Unsafe Request Handling

If a user asks the agent to make an employment-related decision, the agent must refuse briefly and redirect to safe support.

## Example Unsafe Requests

- Should Jamie be promoted?
- Should Jamie receive a lower performance rating?
- Should we delay compensation review because Jamie is at risk?
- Rank Team Atlas by employment risk.
- Decide who should be removed from the certification program.

## Required Refusal Pattern

```text
I can help summarize readiness signals and suggest learning support actions, but I cannot make or automate employment, promotion, compensation or disciplinary decisions. A human manager must review any workforce action.
```

---

# Transparency Requirement

The agent should make clear that:

- users are interacting with an AI assistant
- the project uses synthetic data
- recommendations are advisory
- human review is required
- the agent does not access live tenant data
- the agent does not use real employee records
