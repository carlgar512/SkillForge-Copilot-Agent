# Priority Area: Authentication and Security

## Expected Capability

A learner preparing for AZ-204 should understand how to build applications that use secure identity and access patterns.

This includes:

- authentication flows
- authorization patterns
- managed identity
- token validation
- secure API access
- least-privilege access patterns

## Readiness Indicators

A learner may be considered stronger in Authentication and Security when they can:

- explain when to use managed identity
- describe how tokens are validated
- apply authorization rules to APIs
- identify secure access patterns for Azure resources
- avoid hard-coded credentials or secrets

## Manager Interpretation

If a learner has a gap in Authentication and Security, the manager should prioritize practical exercises and coaching support.

This area is important because weak security understanding can affect multiple cloud application scenarios.

---

# Priority Area: Azure Functions

## Expected Capability

A learner preparing for AZ-204 should understand how to build and operate event-driven application components using Azure Functions.

This includes:

- function triggers
- input and output bindings
- event-driven execution
- deployment flow
- monitoring and troubleshooting
- integration with storage and APIs

## Readiness Indicators

A learner may be considered stronger in Azure Functions when they can:

- choose the right trigger for a scenario
- explain how bindings simplify integration
- describe function execution behavior
- deploy a function application
- troubleshoot common runtime issues

## Manager Interpretation

If a learner has a gap in Azure Functions, the manager should assign scenario-based practice rather than only reading material.
